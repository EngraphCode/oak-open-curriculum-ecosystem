# delivery/ — release delivery lanes

Delivery-class plans for the first major release. Empty at corpus birth
by design: each lane's implementer authors its plan at pickup (per
[the corpus-reset plan](../practice/release-planning-corpus-reset.plan.md)
S3 — lanes route independently as their own gates clear), conforming to
the [V0 schema](../plan-node-schema.v0.md) and naming the milestone plan
via `depends_on`.
