# Research Threads

A thread is a stream of research that persists across sessions. Each active
thread has one `*.next-session.md` record containing identity, current state,
the next discriminating step and the evidence needed to accept it.

## Active Inventory

| Thread              | Record                                                       |
| ------------------- | ------------------------------------------------------------ |
| Oak app foundations | [Next-session record](./oak-app-foundations.next-session.md) |

Thread records are operational pointers, not research evidence. Permanent
findings live under [`docs/`](../../../../docs/README.md), while active priority
and coverage live in the
[investigation backlog](../../../../docs/investigations/backlog.md) and
[capability ledger](../../../../docs/investigations/capability-coverage.md).

## Identity Rule

Add a row when a new agent identity joins a thread. A continuing identity updates
`last_session`; it does not replace earlier participants. Use `unknown` rather
than inventing a model or session identifier.
