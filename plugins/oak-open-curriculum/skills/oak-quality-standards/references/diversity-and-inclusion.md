# Oak quality standards — Diversity and inclusion

**Diversity and inclusion** standards — apply to any surface that depicts or describes people.

**2 standards** — 0 Required (must), 2 Model Practice (should). Judge each against its wording: Met / Partially met / Not met / Not applicable, with evidence and a fix. Required failures are blocking; Model Practice gaps are recommendations.

| ID         | Type  | Standard                                       |
| ---------- | ----- | ---------------------------------------------- |
| QS-254     | Model | Images are culturally accurate                 |
| QS-256 ⚑PE | Model | Images promote diversity and avoid stereotypes |

> ⚑PE marks a standard relevant to practical PE. Scores against the Technical and Pedagogical rubrics use the rubric codes shown — see `technical-rubric.md` and `pedagogical-rubric.md`.
